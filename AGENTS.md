# Bellward

The user starts, stops, and restarts the Bellward server. Agents must leave server lifecycle operations to the user unless explicitly asked to perform one.

## Versioning

Update the `X.Y.Z` version in `package.json` with every project update. Choose the bump based on the most significant change in the update.

- **Major (`X`)** for breaking changes. Reset `Y` and `Z` to zero.
- **Minor (`Y`)** for backward-compatible features or enhancements. Reset `Z` to zero.
- **Patch (`Z`)** for backward-compatible bug fixes and maintenance, including documentation-only changes.
